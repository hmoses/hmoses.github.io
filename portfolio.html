📄 Goose Google Docs Extension

MCP Extension
An MCP (Model Context Protocol) server that gives the Goose AI agent full read/write access to Google Docs and Drive. 18 tools covering document creation, editing, formatting, sharing, and export — enabling AI agents to autonomously manage documentation workflows.
  • 18 MCP tools — create, read, write, append, find/replace, format, share, copy, delete, export Google Docs
  • Built on Model Context Protocol (MCP) — the emerging standard for AI agent tool integration
  • OAuth 2.0 authentication with auto-refresh — secure, local credential storage
  • Submitted to the Goose Extensions Marketplace as a community contribution
  • Enables agents to autonomously create and manage documentation — no human clicks required

Documentation Tool

🎬 Goose Screen Recorder

Developer Tool
A macOS screen timelapse recorder with Goose AI analysis integration. Generates real bash scripts using screencapture and ffmpeg, then enables AI agents to perform frame-by-frame analysis of developer workflows — bridging visual context with agent comprehension.
  • Real screen capture using macOS native screencapture — silent, lightweight
  • Auto video stitching via ffmpeg concat pipeline — produces production .mp4 files
  • Goose AI analysis integration — share recordings with AI agent for frame-by-frame breakdown
  • Fully accessible — ARIA roles, 44px touch targets, focus rings, live regions
  • One-click macOS .app installer with custom Desktop icon
