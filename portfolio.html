MCP Extension

Developer Tool

Product & Platform

I shipped it with 1,000+ prompt templates, five input methods, a fully localized UI in 38 languages, and native apps for iPhone, iPad, and Mac.

  • 5 input methods: type, paste, import, scan (OCR), and dictate — all in 38 languages
