🌐 Poly-Glot AI Workspace

Product & Platform
I designed and developed a multi-AI prompt workspace that lets users write one prompt, send it to up to 9 AI providers (ChatGPT, Claude, Gemini, Grok, Copilot, Perplexity, Mistral, HuggingChat, DuckDuckGo AI), and compare the results side by side. I shipped it with 1,000+ prompt templates, five input methods, a fully localized UI in 38 languages, and native apps for iPhone, iPad, and Mac. I also built and deployed a remote MCP server with 15 developer tools — including Bring Your Own Model (BYOM) endpoints and cross-platform language processing — and distributed it across the Official MCP Registry, MCP.so, Glama, and Hugging Face. To keep the Apple apps, MCP server, entitlements, capabilities, and distribution metadata synchronized, I developed a CI/CD parity and auto-sync pipeline with automated validation, regression testing, webhook-driven repository dispatch, generated Swift capability contracts, MCP synchronization, and registry publishing.
  • Compare Mode sends the same prompt to 2–9 AI providers and displays responses side by side for human evaluation
  • 1,000+ prompt templates across writing, coding, marketing, education, business, and more
  • 5 input methods: type, paste, import, scan (OCR), and dictate, all in 38 languages
  • Fully localized UI in 38 languages, including buttons, labels, menus, templates, input, and output
  • 15-tool MCP server: 7 core tools, 4 BYOM tools, 4 language processing tools — search_templates, get_template, build_prompt, prepare_compare, get_language_options, get_subscription_status, and open_workspace
  • Multi-surface MCP distribution across the Official MCP Registry, MCP.so, Glama, and Hugging Face
  • CI/CD parity automation keeps Apple capabilities, MCP entitlements, release metadata, and registry publishing aligned

⚙️ CI/CD Parity & MCP Auto-Sync Pipeline

CI/CD & DevOps
I developed a parity-driven release pipeline to keep the Apple product, MCP server, entitlements, generated capabilities, release manifests, and registry-facing metadata synchronized as one product surface. Instead of maintaining each distribution target manually, the pipeline validates a shared product contract and automates downstream synchronization and publishing.
  • Parity Check workflow runs on pushes and pull requests and fails CI when shared product capabilities drift
  • MCP Auto-Sync workflow responds to repository-dispatch events generated by App Store lifecycle webhooks
  • Generated Swift capability contract keeps iOS/macOS feature constants aligned with the MCP parity source
  • Entitlement parity validation and regression tests protect subscription gates and shared feature behavior
  • Registry publishing automation connects validated releases to MCP distribution metadata
  • Release manifests and deployment policy enforce parity validation, regression testing, smoke tests, and production release rules
